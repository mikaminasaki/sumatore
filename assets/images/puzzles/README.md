# パズル素材

- 基本操作編は食べ物の5ピース。完成図は `basic-complete.png`、空の台座は `basic-empty-preview.png`。
- 実践編は風景の8ピース。完成図は `practice-complete.png`、空の台座は `practice-empty-preview.png`。

## 重ね方

アプリ用の完成図・台座・透明PNGピースはすべて **1024 × 1024** です。台座の上に `basic-pieces/`（5枚）または `practice-pieces/`（8枚）のPNGを同じ大きさ・同じ位置で重ねます。透明な余白は位置合わせに必要なので、トリミングしないでください。

`*-masks/` のSVGは元の **1254 × 1254** 座標の編集用データです。白い部分が表示範囲です。PNGと直接混在させず、必要に応じて同じ比率で縮小してください。

| コース | フォルダ | ピース |
|---|---|---|
| 基本操作編 | `basic-masks/` | 和牛、塩ソフト、お菓子、ひじき、干物 |
| 実践編 | `practice-masks/` | みそぎ、咸臨丸、チューリップ、新幹線、いさりび鉄道、道の駅、スギ、歴史的な建物 |

カテゴリとの対応は組み込み時に決めます。写真編にはチューリップを使う案です。輪郭を手でなぞった素材のため、拡大時は境目に細かなずれが出る場合があります。

## 軽量化・再書き出し

- 完成図と台座の4枚：合計12,346,777バイト → 2,715,626バイト（約78%削減）。
- 透明PNGピース13枚：合計1,257,124バイト。4枚と合わせても約3.79MiB。
- 1024pxへ縮小し、最大256色のパレットPNGに変換。減色を伴うため、元画像と画素単位では一致しません。透明な外側と半透明の縁を保持します。
- 元の高解像度PNG・SVGはPR #20のコミット `059f87e` とそのGit履歴に残っています。元PNGを重複してアプリ用フォルダに置かないことで容量を抑えています。
- 再書き出し用スクリプト：`scripts/export-puzzle-png.cjs`。元画像・SVGをそろえた別フォルダを入力に指定します。同じ入出力フォルダは指定できません。

```powershell
# sharpは画像加工専用。一時フォルダに入れ、アプリの依存関係は変更しません。
npm install --prefix "$env:TEMP/sumatore-image-tools" --no-package-lock sharp@0.35.5
$env:PUZZLE_SHARP_PATH = "$env:TEMP/sumatore-image-tools/node_modules/sharp"
node scripts/export-puzzle-png.cjs <元画像とマスクのフォルダ> <出力先>
```

まだゲーム画面・記録画面へのピース表示は接続していません。この素材の組み込みは #18 / #10 の続きで行います。
